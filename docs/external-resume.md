# 外部简历：能用在哪些页面

外部简历 = 你在**别处**做好、再上传进来的简历文件（PDF / Word / TXT / Markdown）。
它不是"另一份可编辑简历"，而是**一份原件 + 从原件提取的正文**；这两样都只留在本机。
这篇是它的唯一说明书：能做什么、不能做什么、在哪些页面会被用到。

> 术语：应用里统一叫「**外部简历**」。**原件**专指你上传的那个文件（预览原件 / 导出原件），
> 提取出来的文字叫「正文」。不会出现"上传件""扫描件简历"之类另一套叫法。

## 从哪里进来

**简历中心 → 筛选栏「外部简历 N」**（独立页面，侧栏仍高亮简历中心），或岗位广场某一行右键
「添加外部简历」（岗位由入口定好，上传时不用再选）。单份不超过 10 MB，格式支持
`pdf` / `docx` / `txt` / `md`。

上传后程序在**本机**提取正文，并保留原件：

- 扫描件、纯图片 PDF 也能上传，但会明确标「未提取到文字」，而不是伪装成一份正常简历；
- 显示名称默认取文件名，可改；改名只改**展示名（文件名词干）**，不改变原件里的文件名。

## 列表与详情

列表是「文件 / 关联岗位 / 上传时间 / 最近更新 / 操作」几列，可按列头排序、按岗位筛选、
按关键词搜索；整行右键与行尾「⋯」是同一份菜单（打开详情 / 重命名 / 收藏 / 导出原件 / 删除）。
多选删除会先确认，删除进回收站可恢复；部分失败时如实告诉你删了几份、几份没删掉。

点一行打开**居中详情弹层**，页签是「原件 / 文本 / 编辑 / 历史版本」：

- **原件**：PDF 用内置阅读器按页宽渲染，DOCX / Markdown / TXT 各有预览壳；「导出原件」下载的
  就是上传时那份文件（原名、原扩展名、原字节），历史版本也能单独导出。
- **文本**：上传时提取的正文，以及条目化文本检查（占位符 / 量化比例 / 联系方式 / 篇幅 /
  弱表述；关联了岗位时补关键词覆盖）。**只给条目，不给总分**。
- **编辑**：见下一节。
- **历史版本**：每次改字都会新增一版；两版之间可做**行级对比**（删除红、新增绿），也可以
  「恢复此版本」——恢复是**再写一条新版本**，不会删掉后面的历史。

列表与详情都支持**收藏**和**备注**（"这份投给谁 / 是哪一版"），收藏会出现在**收藏页**。

## 改字：改的是原件，但从不覆盖历史

「编辑」不是把外部简历变成制作台里的结构化简历，而是在**原件上覆盖式改字**：

| 类型 | 能改什么 | 要知道的代价 |
| --- | --- | --- |
| PDF | 按「块」改一段水平文字 | 字体换成系统中文字体（不是原字体），块内按原宽度重新断行；页数不变。新文字变高时可以先把文字改短，或点「下移下方内容」 |
| Word (.docx) | 按「段落」改 | 逐字沿用原 run 的格式；**表格里的文字暂不支持** |
| TXT / Markdown | 整篇正文 | 按原编码写回，原来有没有 BOM 都照原样保留 |

扫描件、已转曲（文字变图形）的 PDF、加密或带表单的 PDF、旋转页都不能在线改字——界面会
说明是哪一种，并给「下载原件」让你用本地工具改完再上传。**每次点「应用」都会另存为新版本**，
原件与旧版本都不会被覆盖。

## 在别的页面怎么用它

| 页面 | 用法 | 边界 |
| --- | --- | --- |
| **收藏页** | 与内部简历同列一张表，每行标明来源，点开就是那一份，「⋯」里可跳回简历中心 | 两种简历 id 会撞号，界面靠 `kind` + `ref` 区分，不靠 id 猜 |
| **求职进度** | 编辑记录时「用了哪份简历」可选外部简历；候选只含本岗位 + 通用 | 与内部简历二选一（同时给 422）；只记名字快照，清空关联不清快照 |
| **投递台** | 队列项可指定「这次用哪份外部简历投」，行上显示「外部 · 文件名」 | 与内部简历二选一（同时给 422）；投递记录与进度都带 `external_resume_id`，运行时按它找原件、不复制文件 |
| **岗位匹配** | 可选一份外部简历做**文本级**比对，结果单独一块并标「文本级」 | 只算 JD 词在正文里的字面覆盖，不给参考分、不下准入结论，不与结构化匹配混排 |
| **模拟面试** | 简历材料下拉的「外部简历」组；选中后题目与追问基于正文 | 没有正文的扫描件在下拉里就禁用；提交的是正文快照，不传外部简历 id |
| **求职助手** | 用 `internal:12` / `external:7` 引用；助手读正文来回答与做质量检查 | 读不到正文时如实说明原因，不编内容 |
| **求职统计** | 「简历版本效果」拆成内部、外部两份；行级指标标注「含外部简历」 | 两份不并排比较（id 会撞号，柱子会被读成同一批简历的排名） |

**深链**：`/resumes/external?resume=<id>` 会直接打开那一份，并把参数从地址栏清掉；这份不存在
或已进回收站时给一条可关闭的提示。提醒卡片与收藏页的「在简历中心打开」用的就是它。

## 它不会做什么

- **不转成制作台里的可编辑简历**：没有条目 / 字段 / 版式，也不参与制作台的 AI 生成与成品导出。
- **不替代原件**：改字另存新版本；历史版本可恢复，但不会改写你已经发出去的那份文件。
- **没有正文就用不了文本类能力**：扫描件能预览、能导出，但岗位匹配、模拟面试与助手分析
  都需要正文；请先补一份有文字层的文件，或用本地工具处理后再上传。
- **PDF 改字不是排版工具**：字体不是原字体，块高变化不会自动重排整页，跨块的大改请回原工具。
