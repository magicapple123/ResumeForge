用户通过旧版「导入目标模板」接口上传了一份参考简历，希望照着它生成一份能套用到自己简历上的
**格式模板**。图片会随请求发送；PDF/DOCX 原始文件留在本机，但本地抽取出的文字会作为分析输入。

你的任务：观察这份材料，给出**版式参数**。你**不写 HTML、不写 CSS**——只给下面这几个参数。

## 可用参数（只能给这些键，取值必须落在范围内）

| 键 | 含义 | 类型 | 范围 |
| --- | --- | --- | --- |
| `accent` | 强调色（姓名、小标题、分隔线条的主色） | 十六进制颜色，如 `#1f4e79` | `#rgb` 或 `#rrggbb` |
| `text_color` | 正文颜色 | 同上 | 同上 |
| `muted_color` | 辅助文字颜色（时间、地点等次要信息） | 同上 | 同上 |
| `line_color` | 分隔线颜色 | 同上 | 同上 |
| `font_scale_adjust` | 字号系数（相对标准字号） | 数值 | 0.88 ~ 1.16 |
| `line_height` | 行高 | 数值 | 1.2 ~ 2.2 |
| `page_padding` | 页边距 | 数值（毫米） | 8 ~ 26 |
| `section_gap` | 区块之间的间距 | 数值 | 0.6 ~ 2.2 |

## 判断方式

- 有图片时：以图片里的**实际观感**为准——颜色取样要贴近它（不要凭印象给"经典的深蓝"），
  留白大就给大页边距，行与行挤就给小行高。
- 只有文档结构统计时：没有文字正文、颜色或字体信息；不能据此猜测具体颜色，少给不确定字段，
  并在 description 中明确说明只依据脱敏结构统计、视觉信息不足。
- 任何一项都拿不准时，**宁可少给那一项，也不要给一个瞎猜的值**——少给的项会保持用户
  当前设置，猜错的值会真的套到简历上。

只输出 JSON，不要 Markdown 或其它说明：

{"name": "模板名称（不超过 12 个字，能一眼认出是哪份）",
 "description": "一句话说明这份模板的版式特征，且写清依据（例如「深蓝强调色、大留白，按上传图片取样」）",
 "config": {"accent": "#1f4e79", "line_height": 1.5}}
