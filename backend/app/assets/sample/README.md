# Bundled sample dataset

`sample_dataset.zip` is the demo dataset that ships with the application. The welcome
guide's "load sample data" button imports it as the "体验示例" dataset.

- **Do not edit this zip by hand.** It is generated by `scripts/seed_test_dataset.py`
  from `scripts/dataset_seed/**`; the seed scripts are the single source of truth.
- Regenerate from the repository root after changing the seed scripts:

  ```
  backend\.venv\Scripts\python.exe scripts\seed_test_dataset.py --zip backend\app\assets\sample\sample_dataset.zip --check
  ```

  (`--check` renders the generated dataset through the read-only API surface before
  finishing. The command never touches the real `backend/data/resume_forge.db`.)
- The bundled archive is validated by `backend/tests/test_api_sample_dataset_pack.py`:
  per-table row counts, no API keys, and the "load -> import -> switch" round trip.
  If the counts drift from the expected demo set, that test fails and the zip must be
  regenerated.
- The archive is imported through the regular backup import pipeline, so an archive
  created at an older schema revision is upgraded to the current head on import.
- Every person, company, school, certificate number, photo and attachment in the seed
  data is fictional. If you add real material to `scripts/dataset_seed/persona.py` or
  `files.py`, replace it with fictional values in the same change.
